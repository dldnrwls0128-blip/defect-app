# 하자관리 (defect-app)

DTspace 하자관리 엑셀(Export Excel)을 폰에서 가져와 세대별 미시공·파손을 공종/업체별로 보고, 처리상태·메모·조치 전후 사진을 기록하는 오프라인 PWA.

- 빌드 없음: `python3 -m http.server 8080` 후 http://localhost:8080
- **하자 데이터는 저장소에 없습니다.** 앱에서 엑셀을 선택하면 그 폰의 IndexedDB(`haja-gwanri`)에만 저장됩니다. 서버 전송 없음.
- 재가져오기: 순번 기준 병합. 내 상태·메모·완료일·사진은 유지. 오래된 엑셀이면 확인창.
- 미시공 = 유형 '미시공' 또는 하자내용에 '미시공'/'미설치'. 파손 = 유형 '파손' 또는 하자내용에 '파손'.
- 검색: `9동 1203`, `12 203`, `309-1203`, `9동`(세대 그리드), 글자(하자내용 검색).
- 백업 zip: 내 기록(edits.json) + 사진. 하자 원본은 포함하지 않음(엑셀 재가져오기).
- 라이브러리: SheetJS xlsx 0.18.5 (vendor/xlsx, Apache-2.0), JSZip 3.10 (vendor/jszip, MIT/GPLv3).
